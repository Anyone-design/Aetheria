# Aetheria — Next-Gen Command Center & Planner

A futuristic cyberpunk glassmorphism workspace and task management platform powered by Node.js built-in SQLite, Web Audio API synthesizers, and hardware-accelerated interactive starfields.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Anyone-design/Aetheria)

## Features
- **Zero-Dependency Architecture:** Pure Node.js built-in SQLite (`DatabaseSync`) and Web Crypto HMAC/Scrypt.
- **Cyberpunk Glassmorphism UI:** 4 cyber themes (Neon Cyan, Matrix Emerald, Solar Amber, Deep Void).
- **Interactive Constellation Canvas:** Hardware-accelerated particle starfield with shockwaves and bursts.
- **Spatial Web Audio Synthesizer:** Procedural key clicks, chords, and UI feedback without external audio files.
- **Priority Missions & Neural Scratchpad:** Persistent to-do tracking and auto-saving notepad.
